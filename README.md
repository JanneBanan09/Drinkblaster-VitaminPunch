# Drinkblaster Vitamin Punch

GitHub Pages-redo hemsida.

## Publicera

1. Ladda upp `index.html`, `styles.css` och mappen `assets` till ditt GitHub-repository.
2. Gå till Settings > Pages.
3. Välj Deploy from a branch.
4. Branch: main.
5. Folder: /root.
6. Save.

Efter en stund får du en länk till hemsidan.
